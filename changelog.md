  - красивий вивід з рамками;
  - дисклеймер про відповідальність (AS IS);
  - підтвердження встановлення: [Volume+] Так / [Volume-] Ні, за замовчуванням — Ні (скасування);
  - при відмові модуль скасовується без залишків.
- Виправлено інсталяційний процес:
  - ASCII-рамки замість Unicode (не ламаються в KernelSU-Next);
  - логіка підтвердження: [Volume+] перемикає на «Так», [Volume-] підтверджує вибір;
  - прибрано emoji з виводу.
- Виправлено вибір у KernelSU-Next:
  - зчитування кнопок через `logcat` (Android KeyEvent) — аналогічно модулю Ace6TDV;
  - fallback на `read "$OUTFD"` для Magisk;
  - таймаут 5 с без натискання = скасування.
- Виправлено втрату ранніх натискань:
  - натискання Volume+/−, зроблені під час показу дисклеймера, тепер враховуються (лог перевіряється до скидання буфера);
  - видиме перемикання вибору: `>` маркер на [1] Так / [2] Ні;
  - [Volume+] перемикає, [Volume-] підтверджує;
  - вивід переведено на простий формат (без ASCII-рамок) — не спотворюється в логу KernelSU-Next.
- Перевипущено реліз (оновлено changelog, перепаковано архів, оновлено sha256 в `update.json`).
- Виправлено видимість вибору:
  - поточний вибір (Так/Ні) показується одразу, до першого натискання;
  - рядки розділяються порожніми `ui_print` — KernelSU-Next склеює послідовні виводи;
  - оновлено GitHub Actions: `actions/checkout@v5`, `softprops/action-gh-release@v2.2.1` (прибрано попередження про Node.js 20).
